プライバシーポリシー

制定日: 2026-11-17

取得する情報

本アプリ (WNL Clips Uploader) は、Google の OAuth 認証を通じて、運営者自身の YouTube チャンネルへのアクセス権 (動画のアップロードとサムネイル設定) のみを取得します。

利用目的

取得したアクセス権は、運営者のチャンネルに切り抜き動画をアップロードする目的にのみ使用します。

保存と第三者提供

認証情報は運営者の端末内にのみ保存し、第三者に提供・販売・共有することはありません。運営者以外の利用者の個人情報は取得しません。

Google API の利用

本アプリによる Google API から取得した情報の使用は、Google API Services User Data Policy (Limited Use 要件を含む) に従います。YouTube API Services を利用しており、YouTube 利用規約 および Google プライバシーポリシー が適用されます。

アクセス権の取り消し

Google アカウントの権限ページ からいつでも取り消せます。
